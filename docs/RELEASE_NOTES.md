# SwyfPatcher v2.6.0

Универсальный неофициальный патчер, включающий **локальную нейроозвучку Qwen3 TTS** в игре *Scam With Your Friends* на слабом железе: ноутбуках и встроенных GPU.

## Главные изменения

- 🔓 **Локальный Qwen3 на любом железе** — снята программная проверка совместимости (оригинал требовал VRAM ≥ 5632 МБ и узкий список вендоров/девайсов, отсекая ноутбуки и iGPU).
- 🔀 **Переключатель бэкенда** — `--backend auto|cpu|vulkan`. Vulkan (`ggml-vulkan.dll`) и CPU (`ggml-cpu-alderlake.dll`, AVX2) переключаются одной командой на живой DLL, без переустановки патча — удобно для A/B-замера скорости.
- ⏱ **Щедрые таймауты генерации** — подготовка 20→120 с (×2), отмена запроса 30→300 с, ожидание первого звука 20→300 с, фрагмент 30→120 с. Медленный старт больше не рвёт озвучку.
- ✂️ **Образец голоса 10→3 с** — быстрее префилл, качество клона сохраняется.
- 🛡 **Безопасность прежде всего** — совместимость по точным SHA-256 всех трёх игровых DLL, сверка исходных байтов по 7 диапазонам, атомарная замена, автоматический бэкап и откат одной командой.
- 📦 **Ноль зависимостей** — чистый PowerShell, есть в любой Windows 10/11. Никаких SDK, компиляторов и скачиваний.
- 🗂 Репозиторий: лаунчер `SwyfPatch.bat` + логика `src/SwyfPatch.ps1`, читаемый README с таблицами и чек-саммами.

## Установка

1. Закройте игру.
2. Скачайте ZIP или `git clone https://github.com/markkentos/SwyfPatcher.git`
3. Запустите `SwyfPatch.bat` — игра найдётся автоматически.

## Быстрая шпаргалка

```bat
SwyfPatch.bat                        :: пропатчить (auto)
SwyfPatch.bat --backend cpu          :: тест CPU-бэкенда
SwyfPatch.bat --backend vulkan       :: тест Vulkan-бэкенда
SwyfPatch.bat --check                :: только проверка
SwyfPatch.bat --restore              :: откат к оригиналу
```
