# SwyfPatcher v2.7.0

Универсальный неофициальный патчер, включающий **локальную нейроозвучку Qwen3 TTS** в игре *Scam With Your Friends* на слабом железе: ноутбуках и встроенных GPU.

## Главные изменения

- 🆕 **Поддержка сборки игры 2026-10-24** — все смещения перепроверены на новой DLL (код переехал, строковые токены изменились; проверены фактические байты до записи).
- 🤏 **Переключатель моделей `--model q4|q8`** — облегчённая Q4_K_M (~2x быстрее инференс) и стандартная Q8_0 меняются одной командой; оригинал автоматически сохраняется рядом. Q4 берётся из локальной копии, с зеркал Hugging Face или по ручному пути. Обход проверки моделей встроен в патч (размер/хэш моделей больше не мешают кастомным квантованиям).
- 🔀 **Переключатель бэкенда `--backend auto|cpu|vulkan`** — Vulkan (`ggml-vulkan.dll`) и CPU (`ggml-cpu-alderlake.dll`, AVX2) меняются на живой DLL. На Intel Arc со старыми драйверами Vulkan может давать шум вместо речи — тогда используйте `cpu` и обновите драйвер.
- 📚 **Поиск игры через `libraryfolders.vdf` Steam** + реестр + стандартные пути на всех дисках.
- 🔁 **Автообновление старых патчей** — DLL, пропатченные v2.6 и ранее, распознаются и обновляются до нового формата одной командой.
- 🛡 **Безопасность прежде всего** — совместимость по точным SHA-256 трёх игровых DLL, сверка исходных байтов по всем диапазонам, атомарная замена, бэкапы (устаревший бэкап другой сборки автоматически заменяется свежим).
- ⏱ Таймауты генерации: подготовка 20→120 с (×2), отмена 30→300 с, первый звук 20→300 с, фрагмент 30→120 с; образец голоса 10→3 с; `HardwareEligible` всегда `true`.

## Установка

1. Закройте игру.
2. Скачайте ZIP или `git clone https://github.com/markkentos/SwyfPatcher.git`
3. Запустите `SwyfPatch.bat` — игра найдётся автоматически.

## Быстрая шпаргалка

```bat
SwyfPatch.bat                        :: пропатчить (auto)
SwyfPatch.bat --backend cpu          :: стабильный CPU-бэкенд (рекомендуется на Intel Arc до обновления драйвера)
SwyfPatch.bat --backend vulkan       :: Vulkan-бэкенд (быстрее, но нужен свежий драйвер Intel)
SwyfPatch.bat --model q4             :: облегчённая модель (~2x быстрее)
SwyfPatch.bat --model q8             :: стандартная модель
SwyfPatch.bat --check                :: только проверка
SwyfPatch.bat --restore              :: откат к оригиналу
```
